## 2. Release Blocker Resolution Summary

| Blocker ID | Severity | Area | Problem Statement | Resolution Status & Verification |
|---|---|---|---|---|
| **BLK-001** | **P0** | Packaging / Deps | `debian/control` required `nodejs (>= 20.11.0)`, but Ubuntu 24.04 official repos provide `18.19.1`. Launchpad builder would reject dependencies. | **RESOLVED**: Aligned `engines.node` in root and workspace `package.json` and `debian/control` to `nodejs (>= 18.19.0)`. Verified CLI and scan-core run cleanly on Node 18+. |
| **BLK-002** | **P0** | Launchpad Build Isolation | `debian/rules` attempted copying uncurated dependencies. Launchpad chroots have no network access; `node-zod` is absent from Ubuntu archives. | **RESOLVED**: Engineered self-contained upstream source archive (`shipshield_1.0.0.orig.tar.gz`) containing pre-compiled `dist/` and curated production runtime `node_modules` (`commander`, `zod`, `diff`, `yaml`). Zero network egress required during chroot build. |
| **BLK-003** | **P1** | Debian Metadata | `packaging/debian/control` declared `Recommends: gitleaks, trivy, checkov`. `trivy` and `checkov` do not exist in Ubuntu noble archives. | **RESOLVED**: Moved `trivy` and `checkov` to `Suggests: trivy, checkov` and documented installation in `docs/17-ubuntu-installation-and-maintenance.md`. Retained `gitleaks` in `Recommends` (verified present in `noble-updates/universe`). |
| **BLK-004** | **P1** | Security Hardening | `engine.command.ts` contained an insecure Docker fallback path using `execSync` and mounting host root `/:/host:ro`. | **RESOLVED**: Eliminated arbitrary shell execution, removed root host mount, and replaced with safe, array-argument `ProcessRunner` invocations. Hardened `doctor.command.ts` to remove pipe-to-shell recommendations. |
| **BLK-005** | **P1** | Version & Distribution | Version `1.0.0` was hardcoded in multiple locations. Changelog used `stable;` and placeholder maintainer email. | **RESOLVED**: Created centralized `SHIPSHIELD_VERSION` export in `@shipshield/contracts`. Reconciled dynamic versions across CLI, daemon, presenter, and orchestrator. Set target series to `noble` in `debian/changelog`. Configured maintainer identity to `Kashif Memon <Kashifjaanmemon786110@gmail.com>` with `XSBC-Original-Maintainer`. |
| **BLK-006** | **P1** | Missing Source Package | No Debian source package (`.dsc`, `.orig.tar.gz`, `.debian.tar.xz`, `_source.changes`) was generated by previous scripts. | **RESOLVED**: Implemented production packaging pipeline in `packaging/build-deb.sh` producing valid Debian format 3.0 (quilt) source package and verified source `.changes` file via `dpkg-source` and `dpkg-genchanges`. |

## 7. Remaining Manual Actions for Maintainer

1. **GPG Signing**:
   ```bash
   debsign -k <YOUR_GPG_KEY_ID> dist-deb/shipshield_1.0.0-1~ubuntu24.04.1_source.changes
   ```
2. **Launchpad PPA Upload**:
   ```bash
   dput ppa:<YOUR_LAUNCHPAD_USERNAME>/<YOUR_PPA_NAME> dist-deb/shipshield_1.0.0-1~ubuntu24.04.1_source.changes
   ```
3. **Monitor Build**:
   Check `https://launchpad.net/~<YOUR_LAUNCHPAD_USERNAME>/+archive/ubuntu/<YOUR_PPA_NAME>` for build status.
