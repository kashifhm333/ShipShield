# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

The ShipShield team takes security seriously. If you discover a security vulnerability in ShipShield, please report it responsibly:

- **Email:** `memonkashif0001@gmail.com`
- **Subject:** `[SECURITY] ShipShield Vulnerability Report`

Please include:
1. Description of the vulnerability and attack vector.
2. Steps to reproduce or proof-of-concept repository.
3. Potential impact and proposed mitigations if known.

We will acknowledge receipt within 48 hours and work with you to coordinate a safe patch release.
